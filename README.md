# ENHANCING STUDENT AFFAIRS AND SERVICES PORTAL

The Enhancing Student Affairs and Services Portal is a web-based platform developed for Mariano Marcos State University (MMSU) to streamline student organization transactions and improve the management of student affairs services.

It provides a centralized system where recognized student organizations can submit and manage accomplishment reports, financial statements, documents, and renewal applications, while the Office of Student Affairs and Services (OSAS) can review submissions and manage organization records.

# Organization Portal
- Organization account access and organization profile management.
- Accomplishment Report (AR) submission and management.
- Activity, participation, award, and tangible project records.
- Financial Statement (FS) submission and management.
- Document registration, tracking, and file management.
- Renewal application submission and supporting forms.
  
# OSAS Portal
- Review and manage organization information.
- Review submitted Accomplishment Reports.
- Review submitted Financial Statements.
- Manage and track organization documents.
- Review organization renewal applications.
- Access administrative workflows for student organization services.
